# AWS Learning Notes

This repository documents my learning of AWS fundamentals through structured notes, scenarios, and cross-day clarifications.

The goal is to understand **how AWS services behave in real situations**, not just to prepare for exams.

---

## Contents

- `day-01-ec2-basics.md`  
  EC2 fundamentals, instance families, pricing models, and CPU credit behavior.

- `day-02-auto-scaling.md`  
  Auto Scaling concepts including launch templates, desired capacity, and scaling behavior.

- `day-03-load-balancer.md`  
  Application vs Network Load Balancers, multi-AZ design, and how ALB works with Auto Scaling.

- `day-04-iam-core.md`  
  IAM users, roles, policies, credential lifecycle, and secure access patterns.

- `day-05-vpc-basics.md`  
  VPC fundamentals including IP addressing, subnets, Internet Gateway, NAT Gateway, and multi-AZ networking design.

More topics will be added as learning progresses.

- Each file represents one focused learning session
